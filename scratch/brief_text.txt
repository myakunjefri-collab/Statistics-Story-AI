3. Rincian Proyek Akhir Penulisan & Spesifikasi Teknis Proyek Akhir Setiap dokumen laporan dan basis kode proyek mahasiswa WAJIB disusun mengikuti struktur 14 Bab di bawah ini. Setiap Bab mewakili indikator kompetensi teknis yang dievaluasi secara ketat: a) Fondasi Web Semantik & Aksesibilitas (HTML5 & WAI-ARIA) Mahasiswa merancang struktur dokumen menggunakan tag semantik HTML5 (<header>, <nav>, <main>, <article>, <aside>, <footer>) serta atribut WAI-ARIA (aria-expanded, aria-controls, role, keyboard focus management) untuk menjamin aksesibilitas penuh bagi screen reader dan keyboard navigation b) Styling Modern & Zero-Runtime CSS Engine (Tailwind CSS v4) Mengimplementasikan utility-first CSS berbasis Tailwind CSS v4 dengan Rust-based Oxide engine. Mahasiswa wajib menjelaskan migrasi/eliminasi runtime CSS-in-JS lama menuju zero-runtime static CSS extraction guna mengoptimalkan kecepatan kompilasi dan HMR (<5 ms). c) Komponen UI Headless & Design Systems (shadcn/ui & Radix UI) Penerapan Component Ownership Pattern menggunakan shadcn/ui dan primitif Radix UI. Mahasiswa menyusun varian komponen yang type-safe menggunakan Class Variance Authority (CVA) serta memisahkan logika aksesibilitas dari layer styling visual. d) Pemrograman JavaScript Tingkat Lanjut & Eksekusi Asinkron (ES6+) Penguasaan manipulasi DOM, event delegation, lexical scope & closures (serta pencegahan stale closure bug), Promises, Async/Await, Fetch API, serta penanganan struktur data kompleks (Array methods, Destructuring, ES Modules). e) Strict TypeScript & Runtime Schema Validation (TypeScript & Zod) Konfigurasi strict: true dan noUncheckedIndexedAccess: true pada tsconfig.json.

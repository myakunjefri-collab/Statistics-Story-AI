MATRIKS MIGRASI BUILD PIPELINE

Modul 8 Praktikum

Aplikasi: Statistics Story AI • Refactor Struktur: src/ • Path Alias: @/ → src/

1. Ringkasan Eksekutif Migrasi

Pipeline pembangunan frontend Statistics Story AI berhasil dimigrasikan dari framework fullstack Next.js ke arsitektur Single Page Application (SPA) modern berbasis React 19, Vite 8, Strict TypeScript, dan Biome. Fitur utama Statistics Story AI tetap dipertahankan setelah migrasi ke Vite dan telah diverifikasi pada environment pengujian.

2. Matriks Komparasi Build Pipeline (Sebelum vs Sesudah)

Komponen Pipeline Sebelum Migrasi (Next.js 16) Sesudah Migrasi (Vite 8 SPA)
Build Tool & Bundler Next.js 16.3.3 (Turbopack engine) Vite 8.3.0 (Rolldown engine + esbuild minifier)
UI Library & Runtime React 19 (Server Components + Client) React 19 SPA (Client-side Pure SPA)
Type Safety Standard TypeScript 5.7 standard (strict: true) Strict TypeScript (strict + noUncheckedIndexedAccess)
Linter & Formatter ESLint 10 (Flat Config + Plugins) Biome 2.5.13 (Rust toolchain, format & lint terpadu)
Path Alias Konfigurasi @/ → ./ (Root project target) @/ → src/ (Baku, target direktori ./src/*)
Strategi Code Splitting Next.js automatic code-splitting Vite manualChunks (Pemisahan vendor modular)
Development Server next dev (Port 3000) vite (Port 3000, strictPort: true, host: true)
Routing & Guard Next App Router + proxy.ts middleware React Router DOM v7 + <ProtectedRoute>
Backend / Mock API Next.js Route Handlers (app/api/*) Vite Connect Middleware (server/mock-api-middleware)

3. Struktur Direktori Baru (Standard src/)

Organisasi Folder Frontend Bersih:

src/
├── components/  -- Komponen antarmuka (app, auth, dashboard, scenes, ui)
├── pages/      -- Halaman rute SPA (landing, login, register, dashboard, input, hasil)
├── lib/        -- State store (Zustand), TanStack queries, types, validation (Zod)
├── globals.css  -- Styling editorial theme Tailwind CSS v4
├── router.tsx   -- Rute deklaratif React Router dengan auth guard
└── main.tsx     -- Client entry point React DOM createRoot

4. Kebijakan Type Safety & Aksesibilitas

Pengaktifan opsi "noUncheckedIndexedAccess": true diselesaikan dengan penambahan pengondisian aman pada nodelist focus trap dialog (components/ui/dialog.tsx), navigasi tab keyboard (components/ui/tabs.tsx), penentuan tipe koordinat scatter chart tuple [number, number][], dan parser tanggal tanpa menggunakan satupun type assertion any atau bypass @ts-ignore.
